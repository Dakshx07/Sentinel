## Why Sentinel? 🤔

In the fast-paced world of software development, understanding project health, contributions, and potential issues can be a challenge. Sentinel leverages the power of generative AI and stunning 3D visualizations to transform raw GitHub data into actionable insights and an immersive experience.

*   🧠 **Intelligent Insights:** Go beyond metrics with AI-driven analysis of your repositories.
*   🚀 **Unprecedented Clarity:** Visualize complex project structures and activity in an intuitive 3D environment.
*   ⏱️ **Save Time, Boost Productivity:** Quickly identify trends, bottlenecks, and opportunities for improvement.
*   💡 **Innovative Experience:** Engage with your codebase and community in a completely new way.

## 🚀 Quick Start

Get Sentinel up and running in minutes!

```bash
# Clone the repository
git clone https://github.com/Dakshx07/Sentinel.git

# Navigate into the project directory
cd Sentinel

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Core Features

Sentinel is packed with cutting-edge features designed to elevate your development workflow:

*   🧠 **AI-Powered Code Analysis**: Get intelligent summaries, identify potential issues, and generate suggestions using `@google/genai`.
*   🌐 **Interactive 3D Visualizations**: Explore your project's structure, commit history, and contributor network in an engaging 3D space powered by `three.js`.
*   🔗 **Seamless GitHub Integration**: Connect directly to your repositories, fetch data, and manage interactions with `octokit`.
*   ✨ **Modern & Responsive UI**: Built with `React` and `TypeScript` for a fast, intuitive, and robust user experience.
*   📈 **Real-time Project Monitoring**: Keep an eye on the pulse of your projects with dynamic updates and alerts.
